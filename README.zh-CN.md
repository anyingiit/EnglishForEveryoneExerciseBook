## 关于本项目

EnglishForEveryoneExerciseBook 是 anyingiit 的个人仓库之一，用来记录 English for Everyone 练习册系列的笔记。GitHub 上该仓库已被标记为归档。它的全部内容只有一个文件 `English For Everyone Exercise book - Note.md`，其完整正文只有一行"Start Notes..."——也就是说，书中的练习、答案或扫描页都不在其中，只有一个从未真正动笔的占位笔记。

计划中的内容，见 [open issues](https://github.com/anyingiit/EnglishForEveryoneExerciseBook/issues)。

## 开始使用

### 环境要求

- 一个能打开 `English For Everyone Exercise book - Note.md` 的文本编辑器或 Markdown 查看器即可；本仓库没有任何软件包清单、依赖列表或构建配置。

### 安装

没有构建步骤，也没有任何依赖需要安装。克隆仓库即可得到笔记文件的本地副本：

```sh
git clone https://github.com/anyingiit/EnglishForEveryoneExerciseBook.git
cd EnglishForEveryoneExerciseBook
```

## 用法

用编辑器打开 `English For Everyone Exercise book - Note.md`，阅读现有笔记或继续添加：

```sh
$EDITOR "English For Everyone Exercise book - Note.md"
```
